## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `button` — кнопка;
- `site-footer` — подвал сайта.


## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`.

## Использование Flexbox и CSS Grid

- Навигация (`index.html`, `catalog.html`, `contacts.html`) построена на Flexbox: элементы выравниваются по центру, расстояние задаётся через `gap`.
- Карточки товаров на главной и странице каталога размещаются в сетке `grid-template-columns: repeat(3, 1fr)`.
- Внутри карточки содержимое выстраивается в колонку Flexbox, кнопка прижимается к нижнему краю через `margin-top: auto`.
- Страница каталога свёрстана каркасом CSS Grid с областями `grid-template-areas: "filters products"`.
- Блок фильтров (`catalog.html`) не подключается к JavaScript и не влияет на выборку товаров.

Проверить вёрстку можно локально: `python3 -m http.server 8000` и открыть `http://localhost:8000`.
