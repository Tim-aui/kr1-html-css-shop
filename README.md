# Учебный frontend-проект — интернет-магазин

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Реализован многостраничный HTML/CSS-сайт интернет-магазина: главная страница,
каталог товаров, карточка товара, страница оформления заявки и контакты.

## Структура проекта

- `index.html` — главная страница: hero, преимущества, популярные товары;
- `catalog.html` — каталог товаров с блоком фильтров;
- `product.html` — карточка товара: изображение, описание, характеристики, цена;
- `order.html` — форма оформления заявки;
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей с CSS-переменными;
- `js/main.js` — открытие и закрытие модального окна заявки;
- `images/product.svg` — изображение-заглушка для карточки товара;
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## Используемые технологии

- HTML;
- CSS (переменные, состояния, Flexbox, CSS Grid, БЭМ, позиционирование);
- Git;
- GitHub (GitHub Pages).

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина со

## Позиционирование

- `position: relative` — карточка товара (`product-card`) как контейнер для бейджа;
- `position: absolute` — бейджи «Хит», «Новинка» и «Скидка» внутри карточек;
- `position: sticky` — блок фильтров на странице каталога;
- `position: fixed` — кнопка «Наверх» на всех страницах;
- `z-index` — фиксированная кнопка «Наверх».

## Использование Flexbox и CSS Grid

- Навигация на всех страницах (`index.html`, `catalog.html`, `product.html`, `order.html`, `contacts.html`) построена на Flexbox: элементы выравниваются по центру, расстояние задаётся через `gap`.
- Карточки товаров на главной и странице каталога размещаются в сетке `grid-template-columns: repeat(3, 1fr)`.
- Внутри карточки содержимое выстраивается в колонку Flexbox, кнопка прижимается к нижнему краю через `margin-top: auto`.
- Страница каталога свёрстана каркасом CSS Grid с областями `grid-template-areas: "filters products"`.
- Блок фильтров (`catalog.html`) не подключается к JavaScript и не влияет на выборку товаров.

Проверить вёрстку можно локально: `python3 -m http.server 8000` и открыть `http://localhost:8000`.
